# Version files go here

Drop each Eaglercraft **offline single-file** HTML build in this folder, named to
match the `file` field in `versions.json`, e.g.

```
versions/eaglercraft-1.8.8.html
versions/eaglercraft-1.5.2.html
versions/eaglercraft-b1.3.html
```

- Commit them as normal files, **not Git LFS** (LFS files come back as a pointer stub).
- GitHub's per-file limit is 100 MB, which every offline Eaglercraft build fits under.
- You can delete this README once your files are in.
