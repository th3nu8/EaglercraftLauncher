# Games to upload

I checked every game in the Offline HTML Games Pack for a license that allows re-hosting.
Six had one and are already in this folder (see LICENSES.md). The games below didn't. Most are
commercial games (Flash builds, Unity builds, or games carrying a publisher's ad SDK); the rest have
no license, which means the author keeps all rights.

Each one already works in Mist by loading from the pack. Upload its file here with **exactly** the
name shown and Mist switches to your copy automatically. No other changes needed.

- Files over 25 MB can't go through GitHub's website uploader. Use `git` or GitHub Desktop.
- These add up to about 5 GB, so push in batches.
