MIST

Free browser games, a game library and friends — launched from one bookmark.

On a computer or Chromebook

  1. Show your bookmarks bar: Ctrl + Shift + B (⌘ + Shift + B on Mac).
  2. Drag this button up onto the bookmarks bar:
☁ Mist
Then go to any normal website and click Mist in your bookmarks bar.

Can't drag? Add it by hand

  1. Copy the code below.
  2. Create a new bookmark (right-click the bookmarks bar → Add page…).
  3. Name it Mist and paste the code into the URL box.

Good to know

  1. If nothing happens, allow pop-ups for the site you're on and click it again.
  2. Some sites (Google, GitHub) block bookmarklets. Try it on a simpler page.
  3. Bookmarklets don't run on the browser's new-tab page.
